Good to know

A few clear
answers.

Is Meethelper ready to download?Private alpha

Not yet. There is no public installer. This page will link to the Windows download when one is available.

Does it work on macOS?Windows only

The current app is Windows-first. macOS support is not available yet.

Does it identify each speaker automatically?No

The current app labels microphone and remote audio, but does not automatically identify individual speakers.

Can I use it without sending content to a cloud AI service?Yes

Supported local model routes are available. Cloud providers are optional, and any content they receive depends on which provider and feature you choose.
